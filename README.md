🌤️ Weather Forecast App


The Weather Forecast App is a Python-based web application that provides real-time weather updates for any city across the globe. It uses the OpenWeatherMap API to fetch accurate, live weather data and displays it through an interactive and animated GUI built with Flask and HTML/CSS.

⚙️ Features

🌍 Real-time weather data (temperature, humidity, wind speed, and description)

🏙️ City-based search functionality

💻 Flask backend with easy-to-use web interface

🌈 Dynamic background GIFs that change based on weather conditions

📱 Responsive and user-friendly design

🧩 Technologies Used

Python (Flask Framework)

HTML5, CSS3, JavaScript

OpenWeatherMap API

Git & GitHub for version control
